# pain001-fast v0.0.84

## Highlights ⭐️

* **Complete publication evidence**: the shared read-only checker verifies all nine suite repositories and every required GitHub, PyPI, GHCR, MCP Registry and website publication. Daily and post-publication checks retain JSON reports and fail incomplete rollouts.
* **In lockstep with pain001 0.0.84**: the native extension adopts the coordinated iteration and the pinned shared audit action. Existing payment-data behavior is preserved; this release changes publication verification and release documentation.

## Details

Publication metadata and required artifacts are checked independently rather
than inferring ecosystem completion from a single package release. Release
tags remain signed and immutable. Dependency metadata, generated README
sources and packaged version references move together with the suite.

The README identifies the three core helpers that use an importable native
extension automatically and links to the current source and wheel release.
