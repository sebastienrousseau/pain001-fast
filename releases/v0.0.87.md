# pain001-fast v0.0.87

## Highlights ⭐️

* **In lockstep with pain001 0.0.87**: the native extension ships the suite's version; validation behaviour and every error message are unchanged.
* **Suite Consistency audits on a schedule only**: it no longer runs on another workflow's completion (`workflow_run`), which ran with the default branch's trust whatever started it, and it pins a core check that knows the five SDK repositories, so the scheduled runs pass again.
* **Devcontainer pinned by hash**: it installs uv from `requirements/devcontainer.txt` with `--require-hashes`, so its first download is pinned by hash as well as by version.
