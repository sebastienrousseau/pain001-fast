# pain001-fast v0.0.86

## Highlights ⭐️

* **In lockstep with pain001 0.0.86**: the native extension ships the suite's version; validation behaviour and every error message are unchanged.
* **Fallback matches the extension**: the pure-Python fallback now refuses IBANs and BICs with non-ASCII characters, as the compiled extension does.
* **Rust held to 100% coverage and the complexity ceilings**: `src/lib.rs` is split into `iban`, `bic`, `charset` and `batch` modules, every binding has Rust unit tests, and `make check` gates line and function coverage, rustdoc and clippy's complexity lints.
* **Fuzzed validators**: a cargo-fuzz harness checks each entry point's contract on arbitrary text, on pull requests, weekly and through the committed seed corpus in `cargo test`.
