# Contributing to pain001-fast

Thank you for contributing to `pain001-fast`.

## Guidelines

- All contributions must pass `cargo test --no-default-features`, `cargo clippy`, and `pytest`.
- Maintain 100% test coverage for line and branch.
- Commits must use Conventional Commits format with DCO sign-off (`git commit -s`).
- All code must include SPDX license identifiers.
